# 🛒 ShopEase — Responsive E-Commerce Application

ShopEase is a modern, responsive, single-page e-commerce store built from scratch with pure frontend technologies. It simulates a realistic shopping workflow including product catalog browsing, live search, category-based filtering, interactive cart calculations, checkout confirmations, and client-side customer session persistence.

---

## 🌟 Key Features

* **Sleek Customer Authentication:** Animated login and registration card supporting password visibility toggling.
* **Persistent Sessions:** Customer profiles and credentials persist in browser `localStorage` across page refreshes.
* **Curated Visual Catalog:** Emojis replaced with high-resolution Unsplash product images with smooth zoom-on-hover scale animations.
* **Font Awesome Stars:** Ratings dynamically generate solid, half-solid, and hollow stars based on item scores.
* **Instant Search & Filters:** Search products instantly or filter catalog lists using nav links or filter pills.
* **Smart Shopping Cart:** Floating sidebar cart with quantity controls, clear button, subtotal summation, shipping addition, and automatic **5% discount** for orders over ₹2,000.
* **Checkout Simulation:** Simulates placing an order and outputs a randomized Order Confirmation ID.

---

## 🛠️ Technology Stack

* **Structure:** HTML5 (Semantic elements)
* **Styling:** CSS3 (Variables, CSS Grid, Flexbox, Keyframe Animations)
* **Interactions:** JavaScript ES6+ (DOM manipulation, LocalState, browser localStorage APIs)
* **Icons:** Font Awesome 6 (Free CDN)
* **Fonts:** Google Fonts (Outfit, Syne, DM Sans)

## 🚀 Getting Started

No servers or package installations are required to run this project.

1. Clone or download this project folder to your local machine.
2. Double-click **`index.html`** or right-click and choose **Open with Live Server** / open it in any web browser.
3. Browse, search, sign up, add items to the cart, and test the checkout system!
